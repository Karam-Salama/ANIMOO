## 📖 Overview
**Animoo** is a sleek, modern wildlife and nature discovery mobile application designed with a focused UI/UX case study and built using **Flutter**. It offers users an immersive way to explore wildlife documentaries, 4K animal photography, species profiles, and interactive community features.

## ✨ Features

- **📑 Onboarding & Splash:** Immersive multi-step introduction flow with custom visual grid overlays.
- **🔐 Auth Suite:** Login, Registration with profile photo picker, OTP code verification, and Password Reset.
- **🐾 Explore & Categories:** Categorized animal directory (Dogs, Cats, Rabbits, Wild, etc.) with custom media upload support.
- **➕ Animal Management:** Create custom categories and list new animals with description and image attachments.
- **🔍 Search & Filter:** Instant search capabilities across categories and animal listings.
- **📡 Offline Mode:** Integrated empty-state screen handling `No Internet Connection` gracefully.
- **🎨 Custom Design System:** Built-in dark forest palette (`#0D302A`), custom inputs, serif headings, and rounded card styling.
